# chrome-ext-wiktionary

A simple Chromium extension to look up selected text on Wiktionary.

1. Download the repository - click Code then Download ZIP or clone and run `zip -r chrome-ext-wiktionary.zip . -x '.git/*'` or `powershell.exe -NoProfile -Command "Compress-Archive -Path * -DestinationPath ./chrome-ext-wiktionary.zip -Force"`
1. Extract the ZIP somewhere permanent
1. In Chrome, open: [chrome://extensions](chrome://extensions)
1. Turn on Developer mode.
1. Click `Load unpacked`
1. Select the extracted `chrome-ext-wiktionary` directory — the directory containing `manifest.json`, `background.js`, etc.

Chrome should install it immediately.
